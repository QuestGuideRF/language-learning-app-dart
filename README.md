# Изучение языков на Flutter

Исходники интерфейса приложения на Dart с Flutter и Provider. Главный экран показывает приветствие, дневную цель, список языков и примеры рекомендованных уроков.

## Структура

- [`main.dart`](main.dart) — точка входа, нижняя навигация, маршруты урока, упражнения и профиля.
- [`home_screen.dart`](home_screen.dart) — разметка главного экрана и взаимодействие с провайдерами.

**Статус:** фрагмент Flutter-приложения, не готовая сборка. В репозитории отсутствуют `pubspec.yaml`, каталоги `providers/`, `widgets/`, экраны урока, упражнений и профиля. Импорты в `main.dart` и `home_screen.dart` ссылаются на отсутствующие пути. Для запуска необходимо восстановить эти компоненты, переместить исходники в структуру Flutter-проекта и проверить совместимость со свежей версией Flutter (некоторые свойства темы устарели).
