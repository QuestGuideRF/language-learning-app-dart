# Изучение языков на Flutter

Исходники интерфейса приложения на Dart с Flutter и Provider. Главный экран показывает приветствие, дневную цель, список языков и примеры рекомендованных уроков.

## Структура

- [`main.dart`](main.dart) — точка входа, нижняя навигация, маршруты урока, упражнения и профиля.
- [`home_screen.dart`](home_screen.dart) — разметка главного экрана и взаимодействие с провайдерами.

Для запуска нужны манифест `pubspec.yaml`, провайдеры, виджеты и остальные экраны из полной копии проекта.
